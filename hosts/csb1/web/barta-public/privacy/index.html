turbogmailify-barta

Privacy and data use

Last updated: 20 September 2026.

Purpose and access

This personal tool transfers messages retained in its operator's Hover mailbox to the operator's authorised Gmail account. It processes messages, headers and attachments for this transfer. Google access is limited to the Gmail API permission to insert messages (gmail.insert); the tool does not request permission to read or delete existing Gmail messages.

Processing and storage

Transfers run on the operator's private infrastructure. Messages are processed there and stored by Hover and Google under their respective account settings and policies. After Gmail accepts an import, the corresponding source message is scheduled for deletion from Hover. Operational logs may contain message metadata, including subjects; this service does not promise exactly-once delivery.

Credentials are kept in encrypted configuration at rest and supplied to the running bridge through a restricted local file. Operational monitoring should expose only status, counts and timestamps.

Use and sharing

Data is used only for mailbox transfer and operation of this tool. It is not sold, used for advertising, or used to train AI models. Messages necessarily pass between Hover, the operator's infrastructure and Google.

Control

The operator can stop the bridge and revoke its Google access. Imported messages remain in Gmail until removed under the account owner's normal controls. Contact the operator using the support email shown on the Google consent screen.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.
